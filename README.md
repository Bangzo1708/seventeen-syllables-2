A deterministic Python program that writes one original 5-7-5 haiku about debugging to /output/entry.txt: "A breakpoint waits, still / the program runs right past it / that branch never runs". No network, no randomness, no clock — the haiku is a constant in the code, validated against the competition gate (UTF-8, 1–200 characters, exactly three non-empty lines, LF endings, one trailing newline) before writing, then read back and verified byte-for-byte.

## Run it

```sh
python3 main.py
```
